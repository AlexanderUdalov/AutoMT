# AutoMT

Личный гараж и план технического обслуживания автомобилей. Адаптивный интерфейс
поддерживает телефон и десктоп, светлую и тёмную системную тему.

## Возможности

- Регистрация, вход, смена имени и пароля, выход и удаление аккаунта.
- Несколько автомобилей, основной автомобиль, фото, VIN и текущий пробег.
- Запуск с экрана «Домой» iPhone с иконкой AutoMT и общей областью навигации.
- Несколько фото автомобиля, просмотр на весь экран и перелистывание свайпом.
- Регламентные и пользовательские работы, остаток до ТО, просрочка,
  выполнение и пропуск работ, удаление работы из плана с сохранением истории.
- История ТО и использованные расходники с брендами и артикулами.
- Напоминание обновить пробег через неделю с возможностью отключения.
- Личные заметки для каждого автомобиля: текст, чек-листы и ссылки.
- Компактная мобильная панель автомобиля; логотип скрывается при прокрутке.

## Локальный запуск

Нужен SDK .NET 9 или совместимый более новый SDK с runtime .NET 9.

```sh
dotnet run --project Sources/Backend/AutoMT.csproj
```

Приложение доступно по адресу `http://localhost:5291`. Бэкенд также раздаёт
фронтенд из соседнего каталога `Sources/Frontend`; отдельная сборка JavaScript
не требуется. Иконки поставляются локально в `Sources/Frontend/vendor`.

По умолчанию используется SQLite `auto_mt.db` в рабочем каталоге сервера.
Для отдельной базы задайте `ConnectionStrings__AutoMT="Data Source=/path/test.db"`.

## Проверки

Проверки API создают и удаляют тестовые аккаунты. Запускайте их с отдельной
тестовой базой, а не с рабочим сервером:

```sh
# Сервер должен быть запущен на localhost:5297 с отдельной базой
node --test Tests/api-smoke.mjs

# Проверка добавления таблицы заметок в существующую базу (после Debug-сборки)
python Tests/migration-smoke.py

# Дополнительно: Playwright + установленный Microsoft Edge
node Tests/browser-smoke.cjs

# Настройки приложения, фото, возврат назад и высота мобильного окна
node Tests/mobile-webapp.cjs
# Для проверки в установленном Playwright WebKit задайте AUTOMT_BROWSER=webkit
```

`AUTOMT_TEST_URL` меняет адрес тестового сервера. Для установленного вне проекта
Playwright можно задать `PLAYWRIGHT_MODULE` с путём к пакету.

После обновления сайта удалите старый ярлык на iPhone и добавьте AutoMT заново
через Safari → «Поделиться» → «На экран Домой», чтобы применились новая иконка
и настройки приложения. Если доступен переключатель «Открывать как веб-приложение»,
оставьте его включённым.

## Деплой

Push в `master` запускает `.github/workflows/deploy.yml`: сборку .NET, проверку
API с временной базой, загрузку на существующий VPS и обновление приложения.
Используются существующие GitHub secrets `VPS_HOST`, `VPS_USER`, `VPS_KEY`.

Перед обновлением сервис останавливается, файлы приложения и база копируются
в `/var/backups/automt/<timestamp>`. Пользовательские изображения остаются на месте.
После запуска проверяется `/api/health`. При ошибке восстанавливаются прежние
файлы приложения; рабочая база при автоматическом откате не заменяется.
Версию фронтенда можно проверить по `/version.json`.

Для существующей базы при старте выполняется идемпотентное добавление таблиц
`VehicleNotes` и `VehiclePhotos` с индексами. Существующие фото из `ImageUrl`
добавляются в галерею без изменения файлов и дублирования при перезапуске.
Существующие таблицы, автомобили, пользователи и
история обслуживания не пересоздаются. Регламенты остаются в `TypesConfig.json`,
пользовательские типы — в существующей таблице `CustomTypes`.
