# AutoMT — Vision

## Что это такое
AutoMT (auto maintenance, AMT) — это персональный помощник для своевременного техобслуживания автомобилей. Он помогает отслеживать состояние автомобилей, планировать техосмотры, напоминать о необходимых действиях (замена масла, страховка, ТО) и вести базу данных по каждому авто.

## Проблема
Автовладельцы (особенно с несколькими машинами) часто забывают о регламентных процедурах или теряют информацию о прошлом обслуживании. Сервисы вроде Google Calendar слишком общие, а полноценные системы автосервиса — избыточны.

## Решение
Простой веб-сервис, адаптированный под использование с мобильных устройств, который:
- Хранит данные об автомобилях и историю техобслуживания
- Автоматически расчитывает будущие работы
- Позволяет прогнозировать и своевременно выполнять технические работы
- Не требует подключения к внешним API
