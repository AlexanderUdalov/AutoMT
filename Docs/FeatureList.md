# AutoMT — Feature List

| ID  | Название                       | User Story                                                                                             | Приоритет    |
| --- | ------------------------------ | ------------------------------------------------------------------------------------------------------ | ------------ |
| F1  | Регистрация / Вход             | Я как пользователь хочу зарегистрироваться и входить в приложение, чтобы работать с данными            | Обязательный |
| F2  | Добавление авто                | Я хочу добавить автомобиль, указав его VIN, или вбив вручную                                           | Обязательный |
| F3  | Список автомобилей             | Я хочу видеть список всех своих авто и их параметры (пробег, модель)                                   | Обязательный |
| F4  | Изображения авто               | Я хочу видеть изображение моего авто в его карточке и не хочу вручную его загружать                    | Средний      |
| F5  | Парсинг VIN                    | Я не хочу вручную выбирать марку и модель авто                                                         | Средний      |
| F6  | Проверка авто по VIN           | Я хочу иметь возможность быстро проверить историю регистарции авто, юридические ограничения и подобное | Низкий       |
| F7  | Напоминания                    | Я хочу устанавливать напоминания на конкретные действия (ТО, страховка)                                | Обязательный |
| F8  | Прогнозирование ТО             | Я хочу видеть приближающиеся работы по моим авто                                                       | Обязательный |
| F9  | Редактирование пробега         | Я хочу периодически обновлять пробег моего авто для болеее качественного прогнозирования               | Обязательный |
| F10 | Прогнозирование пробега        | Я не хочу вбивать пробег слишком часто, он должен прогнозироваться в соответвии с историей             | Обязательный |
| F11 | История обслуживания           | Я хочу сохранять события техобслуживания для каждого автомобиля                                        | Обязательный |
| F12 | Расходники                     | Я хочу сохранять список (артикулы и марки) расходников, которые использовались при ТО                  | Обязательный |
| F13 | Уведомления                    | Я хочу иметь возможность добавить уведомление для прибоижающегося события                              | Высокий      |
| F14 | Темing UI (тёмная тема и т.д.) | Я хочу выбрать тему оформления                                                                         | Низкий       |
| F15 | Экспорт / импорт данных        | Я хочу выгрузить или загрузить данные в читаемый вид, JSON или CSV                                     | Высокий      |
| F16 | Управление аккаунтом           | Я хочу сменить пароль или удалить аккаунт                                                              | Средний      |
| F17 | Прогнозирование расходов       | Я хочу видеть приблезительную стоимость работ опираясь на историю и инфляцию                           | Средний      |
